┌─────────────────────────────────────────────────────────────────────────┐
│ 🔄 WORKFLOW                                                             │
└─────────────────────────────────────────────────────────────────────────┘

  1. Admin clicks "Import" button
  2. Modal opens
  3. Admin downloads template (optional)
  4. Admin prepares Excel file with asset data
  5. Admin selects category (all assets go here)
  6. Admin uploads Excel file
  7. System validates data
  8. System imports valid assets
  9. System creates history entries
  10. Success message displayed
  11. Asset list refreshes automatically
  12. Done! Assets are now in the system

  Time Required: 30 seconds to 2 minutes (depending on file size)

┌─────────────────────────────────────────────────────────────────────────┐
│ 🔧 TECHNICAL DETAILS                                                    │
└─────────────────────────────────────────────────────────────────────────┘

  Backend:
  • Language: JavaScript (ES6+)
  • Framework: Node.js with Express
  • Database: MongoDB with Mongoose
  • Excel Parser: XLSX library (v0.18.5)
  • Authentication: JWT

  Frontend:
  • Framework: React 18
  • UI: Tailwind CSS + custom components
  • Icons: Lucide React
  • HTTP: Axios
  • Excel Generation: XLSX library

  API Endpoint:
  • URL: POST /api/assets/import
  • Auth: Bearer token (admin only)
  • Input: base64 Excel file + category ID
  • Output: success/error with count
